# Store assets

These files are used for the Prayer Times listing on KDE Store:

- `prayer-times-logo.png`: product logo.
- `arabic-dark.png`: Arabic interface using the dark appearance.
- `english-dark.png`: English interface using the dark appearance.
- `english-light.png`: English interface using the light appearance.
- `english-blue.png`: English interface using the blue dark appearance.
- `compact-panel.png`: compact Plasma panel representation.

The vector source for the product logo is already tracked at
`contents/images/mosque-svgrepo-com.svg`, so it is not duplicated here.

Logo artwork credit: SVG Repo / EmojiOne.
